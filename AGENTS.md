## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Design Context

This is a **brand-register web portfolio** for Muhammad Reza Ananta, themed after Persona 5's visual language — bold, stylish, rebellious. Key principles:

- Committed red palette (30-60% surface) against pure white bg and near-black ink
- Single sharp geometric sans-serif throughout (DM Sans recommended)
- Flat elevation — no shadows, depth via contrast and scale
- Choreographed scroll-driven reveals with reduced-motion fallback
- Every element earns its place; the work is the main event
- Anti-referenced: no standard dev-portfolio template, no gaming-fan-site tropes

See `PRODUCT.md` and `DESIGN.md` for the full strategic and visual specification. Run `/impeccable document` to refresh DESIGN.md once there's code with real tokens.
